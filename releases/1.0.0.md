# Volumetric Wing Vapor 1.0.0 — First release

An add-on for [KSP Wingtip Vortex](https://github.com/PogKai/ksp-wingtip-vortex): its wing vapor, drawn as one soft volumetric cloud over each wing with [Waterfall](https://github.com/post-kerbin-mining-corporation/Waterfall)'s shader, in place of the particle puffs.

## Highlights

* One cloud per wing, fitted to the vapor each frame: it starts along the wing's leading edge, takes
  the wing's sweep and taper, and joins over the fuselage when both wings are condensing
* Two settings in Wingtip Vortex's window (**Alt+V**): the cloud's thickness, and a switch back to
  the puffs

## Requirements

* KSP 1.12.x
* **Wingtip Vortex 1.5.0** or later. Without it KSP does not load this mod
* **Waterfall** (developed against 0.10.5). Without it the vapor stays as puffs

## Install

Download `VolumetricWingVapor_1.0.0.zip` and drop the `VolumetricWingVapor` folder from it into
`GameData/`.

## Known limitations

* The cloud adds light, so it reads best against sky and can look like a glow against dark terrain
* It covers the main wings only, not a strake or canard ahead of them or a tail well behind
* It is drawn on the craft you fly only
